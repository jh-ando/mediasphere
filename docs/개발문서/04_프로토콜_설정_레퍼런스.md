## 1. 통신 채널

|---|---|---|---|
| UDP 멀티캐스트 | `239.0.0.1:5000`, 30fps | 서버 → 폰·외부 장비 | 타임코드 `{type:"TIMECODE", masterMs, elapsedMs, startAt, isPlaying}` |

| WebSocket | `:3000/playback-control` | 외부 업체 → 서버 | `PLAY_TRIGGER` → `ACK` 또는 `ERROR` (인증 없음) |

## 2. MQTT 토픽

| 토픽 | 방향 | QoS | retain | 내용 |
|---|---|---|---|---|
| `wall/control` | 서버→전체 | 1 | 기본 retain(재접속 폰이 마지막 PLAY/STOP/모드를 받음). 패턴 시작·정지, 컬러, 기기 관리처럼 "지금 이 순간의 동작"은 **non-retain** | 제어 명령 (3장) |
| `wall/device/{id}` | 서버→개별 | 1 | ✔ | 폰별 config(영상 파일, 체크섬, 위치) |
| `wall/pattern/{id}` | 서버→개별 | 1 | ✘ | `TEXT_PATTERN_CELL` |
| `wall/state/color` | 서버→전체 | 1 | ✔ | 현재 컬러 오버레이 상태(재접속 복구용) |
| `wall/ota` | 서버→전체 | 1 | ✔ | `UPDATE_APK` |
| `wall/status/{id}` | 폰→서버 | 0 | ✘ | heartbeat, 5초마다 (5장) |
| `wall/ready/{id}` | 폰→서버 | 1 | ✘ | `{type:"READY", file, checksum}` 파일 검증 완료 |
| `wall/error/{id}` | 폰→서버 | 1 | ✘ | `{type:"ERROR", reason, detail}` reason: `DOWNLOAD_FAILED` / `CHECKSUM_MISMATCH` / `RENAME_FAILED` |
| `wall/ota/status/{id}` | 폰→서버 | 1 | ✘ | `{type:"OTA_STATUS", versionCode, phase, reason?}` phase: downloading / installing / done / failed |

> **주의**: retain 메시지도 이미 연결된 폰에는 실시간으로 그대로 전달됩니다. QoS1은 같은 메시지를 **두 번 받을 수 있다**는 전제로 처리해야 합니다(MODE_VIDEO, config 중복 수신 가드 참고).

## 3. 명령 목록 (`wall/control`)

| 분류 | type | 대상 지정 | 비고 |
|---|---|---|---|
| 영상 | `PLAY` `STOP` `LOAD` | - | PLAY는 `startAt` 절대 시각. 폰은 1초 대기 후 seek→play |
| 파일 | `CHECK_UPDATE` | `targetDeviceIds`(없으면 전체) | 배포 후 미완료 폰만 |
| 기기 관리 | `RESTART_APP` `REBOOT_DEVICE` | `targetDeviceIds` (REBOOT는 필수) | **non-retain** |
| 모드 | `MODE_VIDEO` `MODE_PATTERN` `MODE_TEXT` | - | 절전 = MODE_PATTERN + 검은 화면 |
| 패턴 | `PATTERN_START` `PATTERN_STOP` `SEQUENCE_START` `SEQUENCE_STOP` | - | colorMode: `fixed` / `random` / `randomGray` / `randomShade`. 재생목록은 서버가 큐마다 이 명령들을 보냄 |
| 텍스트 스크롤 | `TEXT_SCROLL` `TEXT_STOP` | - | `rowCounts`, `totalRows`, `refGapRatioX`를 서버가 계산해 실어 보냄 |
| 텍스트 패턴 | `TEXT_PATTERN_STOP` | - | 셀은 `wall/pattern/{id}`로 |
| 컬러 오버레이 | `COLOR_CHANGE` `COLOR_CLEAR` | - | 키오스크용(UI 제거됨, 백엔드는 유지) |
| 식별 | `SHOW_ID` `HIDE_ID` | - | 화면에 deviceId 크게 표시 |
| OTA | `UPDATE_APK` | (토픽 `wall/ota`) | [03_릴리스_OTA_절차](03_릴리스_OTA_절차.md) |

**시간 규칙**: 동시에 시작해야 하는 명령에는 모두 미래의 서버 시각 `startAt`(ms)이 들어갑니다. 폰은 `TimeSyncManager.now()`(서버 시계로 환산한 시각)로 그때까지 기다립니다. 서버의 여유 시간은 다음과 같습니다.

| 명령 | 여유 시간 |
|---|---|
| 컬러 | 2초 |
| 텍스트 스크롤 | 3초 |
| 텍스트 패턴 | 1초 |
| OTA | 3초 |

## 5. heartbeat (`wall/status/{id}`, 5초마다)

| 필드 | 항상 | 설명 |
|---|---|---|
| `deviceId`, `status:"online"`, `timestamp` | ✔ | |
| `versionCode` | ✔ | 앱 버전 |
| `batteryPct`, `charging` | ✔ | 상시 전원이므로 `charging=false`가 케이블 이상 신호 |
| `thermalStatus` | ✔ | 0~6 (PowerManager). 3 이상 = 심각 |
| `batteryTemp` | ✔ | °C |
| `cpuTemp`, `skinTemp` | 기기가 주면 | Device Owner 전용 HardwarePropertiesManager |
| `kiosk` / `kioskSince` / `kioskReturnAt` | ✔ / 정비 중 | `false`면 현장 정비 중 |
| `playerError` | 문제 시 | ExoPlayer errorCodeName |
| `rebootError` | 문제 시 | 예: `NOT_DEVICE_OWNER` |
| `lastExit` | 기록이 있으면 | `{reason, at, detail, afterBoot, intentional(RESTART/REBOOT/UPDATE), before{온도}}`. 서버가 `at`으로 중복 제거 |

서버 판정 기준:

| 판정 | 기준 |
|---|---|
| 오프라인 | 10초 동안 heartbeat 없음 |
| 발열 | thermalStatus ≥ 3 또는 배터리 45°C 이상 |
| 최근 재시작 | 의도하지 않은 종료, 24시간 이내 |

## 6. config.json (폰: `/sdcard/mediasphere/config.json`)

| 필드 | 출처 | 설명 |
|---|---|---|
| `deviceId` | gen_manifest | 1~439 |
| `ssid` | gen_manifest | `MEDIA_01`~`MEDIA_10`. **기록용**이며 앱이 사용하지 않음 |
| `serverIp`, `multicastGroup`, `timecodePort`, `mqttBroker`, `videoPath` | base-config | 전 폰 공통 |
| `colorOverlayAlpha` | base-config(선택) | 기본 0.35 |
| `currentVideo`, `checksum` | manifest | `P001` 형식 파일명, `sha256:...` |
| `row`, `col` | tiles meta (flat) | 평면 그리드 위치 |
| `lat`, `lon` | tiles meta (sphere) | 구체 위치(물리 경도). 있으면 텍스트 스크롤이 구체 계산 사용 |
| `gapRatioX`, `gapRatioY` | flat: manifest `gap` / sphere: 행별 meta | 폰 사이 물리 간격 비율 |

- 파일에는 최초 부트스트랩 값과 `currentVideo`만 남습니다. 최신 위치·간격 값은 `wall/device/{id}`(retain)로 받아 **메모리에만** 둡니다. 그래서 진단할 때는 파일이 아니라 logcat의 "텍스트 스크롤 시작 - row=… gapRatioX=…" 로그를 봅니다.
- 공통값 원본: `pipeline/slicer/base-config.example.json` (대시보드 영상 교체도 이 파일 사용)
