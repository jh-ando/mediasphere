## 절대 하지 말 것
1. 디버그 APK나 다른 키로 서명한 APK를 현장 폰에 설치하기 (이후 OTA 불가)
2. 기기 관리 명령(재시작·재부팅)을 retain으로 발행하기 (재접속할 때마다 반복 실행)
3. 재생·배포·영상 교체 중에 서버 재시작하기
4. 원본 해상도가 바뀌었는데 tiles.json 재사용하기
5. 서버 전원 모드를 '밸런스'로 두기 (동기화 이탈)
6. 폰에 Google/Samsung 계정 추가하기 (Device Owner 재세팅 불가)
