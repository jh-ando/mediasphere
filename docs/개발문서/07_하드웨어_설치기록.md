### 1.1 위도별 배치와 번호

번호 규칙: 경도 0°, 가장 위 행(+64.29°)이 1번이고, 행 안에서는 동쪽(경도 증가)으로 번호가 늘어납니다. 행은 위에서 아래로 진행합니다.

| 위도 | 대수 | deviceId | 경도 간격 | 가로 간격 비율(gapRatioX, 대략) |
|---|---|---|---|---|
| +64.29° | 20 | 1–20 | 18° | 극지방 쪽 ~0.55 |
| +51.43° | 30 | 21–50 | 12° | |
| +38.57° | 40 | 51–90 | 9° | |
| +25.71° | 50 | 91–140 | 7.2° | |
| +12.86° | 50 | 141–190 | 7.2° | |
| 0° | 50 | 191–240 | 7.2° | 적도 ~0.39 |
| −12.86° | 50 | 241–290 | 7.2° | |
| −25.71° | 50 | 291–340 | 7.2° | |
| −38.57° | 40 | 341–380 | 9° | |
| −51.43° | 30 | 381–410 | 12° | |
| −64.29° | 20 | 411–430 | 18° | |
| −77.14° | 9 | 431–439 | 40° | |

- 정확한 행별 gapRatio는 `gen_tiles.py sphere`가 계산해 tiles.json의 `meta`에 저장합니다.
- 전/후면 미러 모드에서 이음매(경도 90°/270°)에 걸치는 폰 8대(위도 ±64.29°/±38.57°)는 단순 crop으로 처리합니다. 화질은 실기기 확인이 필요합니다.
